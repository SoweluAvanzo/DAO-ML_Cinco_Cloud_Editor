# Known Bugs Related to Cinco Cloud
When a Modelelement is selected, and then the canvas, the modelelement changes its parent to the graphmodel. To mitigate that, currently the dao first needs to be clicked, then the element, e.g. permission, won't change to the graphmodel.
Permissions related to that bug will be deleted, since a DaoML model does not allow permissions to be in the model root.
